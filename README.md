# Nexus Tech - Landing Page Moderna em Next.js 14

Landing page institucional de alta performance para empresa de tecnologia e assistência técnica especializada, construída com **Next.js 14 (App Router)**, **TypeScript** e **CSS Puro**.

Projeto criado para fins de portfólio profissional, apresentando boas práticas de Server-Side Rendering (SSR), SEO estruturado com Schema.org, suporte a Dark/Light Mode e responsividade avançada.

---

## 🚀 Tecnologias Utilizadas

- **Next.js 14.2.5** (App Router & Server Components)
- **React 18.3.1**
- **TypeScript 5.5**
- **CSS3 Puro** com CSS Variables, CSS Grid e Flexbox
- **Next/Font** (Google Fonts: *Manrope* e *Sora*)
- **Schema.org JSON-LD** (`LocalBusiness`, `ComputerStore`)

---

## 🛠️ Funcionalidades

- **Tema Claro / Escuro (Dark Mode):** Alternância instantânea com persistência no `localStorage` e detecção de preferência do sistema operacional (`prefers-color-scheme`).
- **Navegação com Rolagem Suave:** Header fixo com efeito *backdrop blur* e links diretos para seções.
- **Catálogo de Serviços Completo:** 6 pilares de atendimento (Manutenção de PCs, Notebooks, Impressoras, Upgrades, Redes e Suporte de TI).
- **Marcas Parceiras Vetorizadas:** Logos oficiais em SVG de alta nitidez que se adaptam automaticamente ao tema escuro.
- **Foco em Conversão:** Botão flutuante de WhatsApp, QR Code interativo e mensagem de orçamento pré-formatada.
- **SEO Otimizado:** Metatags completas, Open Graph e dados estruturados para busca local.

---

## 💻 Como Rodar Localmente

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Abra no navegador:
   ```
   http://localhost:3000
   ```
